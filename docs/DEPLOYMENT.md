# GitHub Pages deployment

1. Replace repository contents with the files in this package.
2. GitHub: Settings → Pages → deploy from the production branch/root folder.
3. The build is written for `https://greaterheight.github.io/FemiOrimoloye/`.
4. Confirm CSS loads at `/FemiOrimoloye/css/styles.css`.
5. Confirm JS loads at `/FemiOrimoloye/js/main.js`.
6. Confirm internal navigation stays inside `/FemiOrimoloye/`.
7. If a custom domain is later supplied, update canonical URLs, sitemap, Open Graph URL/image, manifest start URL and deployment configuration.
