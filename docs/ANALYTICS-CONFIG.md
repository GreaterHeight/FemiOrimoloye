# Analytics Configuration

No analytics IDs were supplied. No IDs are fabricated.

Supported placeholders in `index.html` and all pages:
- GA4
- Google Tag Manager
- Meta Pixel
- LinkedIn Insight
- Microsoft Clarity

Events implemented in this build:
- `cta_start_conversation` when CTA links are activated
- `final_start_conversation`
- `contact_form_validated`

Production activation requires approved IDs, consent requirements, event taxonomy and provider scripts. Verify events in the intended production environment before launch.
