# Version 7 — Language Switch, Site Search & Home Intro Grid

- Added a language selector after Contact in the primary navigation: English, Arabic, French, Deutsch (German), and Chinese. The selection persists between pages; shared interface strings and key homepage content have client-side translations. Arabic sets the document to RTL.
- Added an accessible site-wide search overlay backed by an index of page headings, titles and descriptive text. Supports keyboard Escape and result navigation.
- Rebuilt the homepage intro-grid into a feature-led editorial split layout with three supporting points and a three-image collaboration mosaic inspired by the supplied reference.
- Added three optimised collaboration images to `assets/images/home/`.
- Primary navigation labels are uppercase.

## Translation scope
This static build translates the shared navigation, common calls to action, footer/search controls and key homepage intro content. Long-form editorial copy and article bodies remain in English until professionally translated.
